# JabPoint Product Documentation

Official product specification for the **JabPoint Promo Website**, derived from the client technical assignment (TZ) and aligned with the current React codebase.

These documents are the source of truth for content, UX, and Stage‑1 engineering work. Code docs under [`docs/`](../README.md) describe *how the site is built*; this folder describes *what the product must become*.

| Document | Purpose |
|----------|---------|
| [01 — Product brief](./01-product-brief.md) | Positioning, company facts, brand voice, three-stage vision |
| [02 — Requirements](./02-requirements.md) | Business, user, functional, and non-functional requirements (IDs) |
| [03 — Technical assignment](./03-technical-assignment.md) | Page structure, copy blocks, design system, integrations |
| [04 — Acceptance criteria](./04-acceptance-criteria.md) | Testable acceptance criteria for Stage‑1 delivery |
| [05 — Roadmap & milestones](./05-roadmap-and-milestones.md) | Stage 1–3 roadmap and implementation slices |
| [06 — Traceability matrix](./06-traceability-matrix.md) | Goals → requirements → implementation → verification |
| [07 — Current vs target gap](./07-current-vs-target-gap.md) | Diff between live codebase data and client TZ |
| [Sources](./sources/) | Archived original client materials |
